# Hybrid E2E Automation

Playwright and TypeScript test framework for the Demoblaze UI and Restful Booker API assignment.

## Project structure

- `src/pages` - page objects and page guards
- `src/components` - reusable UI components
- `src/models` - typed API contracts and test-data models
- `tests/ui` - Demoblaze end-to-end tests
- `tests/api` - Restful Booker integration tests
- `.github/workflows` - CI pipeline
- `docs` - original assignment

Implementation details, setup instructions, architecture decisions, and SQL examples will be added during development.
